# AIOI - AI Open Source Impact

> **AI 시대의 오픈소스: GenAI & LLM Ecosystem Contribution**

AI Core Contributor를 양성하는 6주간의 교육 프로그램입니다. AI 오픈소스 생태계에 대한 이해와 실전 기여 역량을 배양합니다.

## 프로그램 개요

| 항목 | 내용 |
|------|------|
| **부제** | AI-Native Open Source Frontier |
| **기간** | 총 6주 (오프라인 2회 + 온라인 4주) |
| **구성** | 오프라인 킥오프 → 온라인 스프린트 → 오프라인 클로징 |
| **멘토링** | 프로젝트별 전담 멘토 배정 |

## 프로젝트 트랙

| 트랙 | 컨셉 | 난이도 |
|------|------|:------:|
| **트랙 A** | AI 도구를 활용하여 기존 오픈소스에 기여 | ★★☆ |
| **트랙 B** | 기존 오픈소스에 AI 기능 추가 | ★★★ |
| **트랙 C** | MCP 서버, AI Agent 등 AI 네이티브 프로젝트 개발 | ★★☆ |

## 주차별 커리큘럼

| 주차 | 주제 | 형태 |
|:----:|------|:----:|
| 1주차 | **Kick-off Day** — 생태계 이해 + 환경 구축 + 팀 매칭 | 오프라인 |
| 2주차 | **코드 분석 Sprint** — 프로젝트 구조 분석 + 이슈 선정 | 온라인 |
| 3주차 | **첫 번째 기여 Sprint** — 첫 PR 생성 + 코드 리뷰 | 온라인 |
| 4주차 | **심화 기여 Sprint** — PR 피드백 반영 + 기술 심화 | 온라인 |
| 5주차 | **최종 Sprint** — PR 마무리 + 데모 준비 | 온라인 |
| 6주차 | **Impact Night** — 성과 발표 + 시상식 + 네트워킹 | 오프라인 |

## 슬라이드 보기

`index.html`을 브라우저에서 열면 주차별 강의 슬라이드에 접근할 수 있습니다. 각 슬라이드는 키보드 좌우 방향키로 넘길 수 있는 프레젠테이션 형태입니다.

## 주요 다루는 기술

- **AI 코딩 도구**: Claude Code, GitHub Copilot, Cursor
- **AI SDK**: Vercel AI SDK, LangChain, OpenAI SDK, Spring AI
- **MCP**: Model Context Protocol 서버 개발
- **AI Agent**: CrewAI, LangGraph 기반 에이전트 구축
- **벡터 DB**: pgvector, ChromaDB

## 라이선스

본 자료는 교육 목적으로 제작되었습니다.

**무단 사용 금지**: 본 저장소의 모든 콘텐츠(슬라이드, 커리큘럼, 리서치 자료 등)는 저작권법의 보호를 받습니다. 사전 서면 허가 없이 복제, 배포, 수정, 상업적 이용 등 무단 사용을 금지합니다.
